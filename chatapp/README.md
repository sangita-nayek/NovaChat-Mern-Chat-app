# NovaChat — Redesigned MERN Real-Time Chat

A portfolio-ready original implementation inspired by the common MERN + Socket.io chat-app architecture. It is **not copied from GreatStack's source code**.

## Features
- MERN stack + Socket.io real-time messaging
- JWT authentication and bcrypt password hashing
- Search users
- Online presence / typing indicator
- Seen/delivered indicators
- Responsive mobile-first chat UI
- Dark/light mode
- Profile avatar via UI Avatars
- Clean frontend/backend separation

## Run locally
1. Install Node.js 18+ and MongoDB.
2. Copy `server/.env.example` to `server/.env` and set values.
3. From the root run `npm install`, then `npm run install-all`.
4. Run `npm run dev`.
5. Open http://localhost:5173.

Create two accounts in two browser windows to test real-time chat.
